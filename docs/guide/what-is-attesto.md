# What is Attesto?

> _This page is being written. Coming in the next docs commit._

Attesto is a thin, open-source receipt validation proxy for mobile in-app
purchases on Apple App Store and Google Play. It verifies purchase tokens
with Apple and Google on behalf of your backend, returning verified
transaction data without interpreting business logic.

See the [README](https://github.com/nossdev/attesto#readme) for the current
short version, or jump to [Quickstart](./quickstart) to run it locally.
